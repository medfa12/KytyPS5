The file contains little-endian instruction DWORDs. With the variable unset,
the affected regression prints `SKIP` rather than claiming coverage. When it is
set, missing, truncated or checksum-mismatched data fails the test. The inline
FNV-1a checksum detects accidental fixture changes; it is not a security trust
anchor. The SHA-256 above identifies the retained payload for independent checks.

The affected regressions keep their original assertions and GPU execution when
the retained inputs are supplied. The NGG fixture contains only the retained
prefix; the test still generates its four-instruction synthetic suffix.
The metadata-fill and bounded-pattern-fill fixtures differ in instruction
ordering and have separate checksums.
The scalar-material loop fixture excludes the generated branch at word 2;
the test reinserts that branch and retains its original target calculations.
The interpolation fixture excludes the generated export/end instructions.
The shared stencil fixture is checked in both CFG and GPU regressions.

Both `shader_cfg_tests` and `shader_recompiler_compute_tests` accept
`--retained-shaders-only` to run these regressions. This mode returns an error
if the fixture root is unset, so a focused acceptance run cannot pass by skipping
all captured inputs. Each loaded fixture prints its name and checked size.
Individual captured opcode examples remain distinct from these program blocks;
this conversion does not establish that every test input is synthetic.
# Additional boot B16 regression

`boot-b16-packed-sdwa.bin`: 160 bytes (40 little-endian DWORDs), SHA-256
`0ade771803e79bcc3124cba0f499588f53abfcf205d4808ed55d0584d08da8d0`,
FNV-1a `0x363d9bb612b558a6`. Retained externally from the mixed boot-instruction
test array; the two encoder expressions were evaluated using the existing VOP1
encoding formula. All original assertions remain. CFG `--boot-b16-only` invokes
this previously uncalled regression and requires this additional fixture (19
total external fixtures; the established focused CFG mode still consumes ten).
The initial failure was resolved by migrating the dormant test to current
uppercase decoder mnemonics and typed SSA. Runtime buffer inputs and a store
after each of its 21 instructions keep every result observable. Checks cover
per-result arithmetic, insertion offsets/widths, sign extension, half rounding,
packing and NaN-correct NClamp emission, followed by SPIR-V validation.
Verified at `7ab81b2c`: both shader targets build, `--boot-b16-only` and the
established focused CFG mode pass without skips; no fixture root returns 2.
